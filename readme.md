# OpenHEIC

**A free Windows image viewer and converter for HEIC and HEIF images.**

OpenHEIC is a simple desktop application designed to help Windows users open, view, and convert HEIC/HEIF images, with support for navigating through images in the same folder.

## Features

- Open HEIC and HEIF images
- View supported image formats
- Navigate to the next and previous images
- Convert images to common formats, where supported by the application
- Simple desktop interface

## Requirements

- Windows 10 or Windows 11
- Python 3
- Dependencies listed in `requirements.txt`

## Run from source

1. Install Python 3 from https://www.python.org/downloads/
2. Download or clone this repository.
3. Open PowerShell in the project folder.
4. Run:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```
